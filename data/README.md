# Distillation ledgers

One row per generated trajectory (no message content; the trajectories themselves are in the Release asset
`training_data.tar`).

* `distill_index_teacher.jsonl.gz` - all 6,586 teacher trajectories (DeepSeek-V4-Flash 3,840, DeepSeek-V4-Pro 2,746) on
  4,628 decision states of the training split: `teacher`, `task`, `state`, `status`, `keep` (passed rules R1-R8),
  `reject` (failed rules), `repaired` (self-check correction turn added), `gap`, `score`, `n_rounds`, `tool_calls`,
  `n_tokens`, `cost_cny`, `fault`, `masked_turns`, `cap_hit`, `tool_errors`, `format_errors`. 5,450 rows have `keep = true`;
  the API cost sums to 1,294.85 CNY.
* `distill_index_self_c1.jsonl`, `distill_index_self_c2.jsonl` - the student self-sampling batches on the hard fault states
  (`teacher` = the student GGUF), filtered with the same rules.

Generated by `src/distill/to_sft.py`.
